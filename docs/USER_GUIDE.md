# User Guide

## Access
1. Open http://localhost:5173
2. Click Employee Login or Admin Login
3. Use credentials:
   - Employee: employee / employee123
   - Admin: admin / admin123

## Dashboard Sections
- Wafer Production: Create and track batches
- Equipment Health: Monitor all equipment
- Yield Analytics: View quality metrics
- Maintenance: Schedule and view maintenance

## Wafer Production
1. Click "New Batch"
2. Enter batch name, product type, total wafers
3. Click "Create"
4. Click "View History" to track progress

## Equipment Health
- View all equipment with status
- Check operating hours
- View health scores

## Yield Analytics
- View average yield
- Check defect rates
- Monitor quality score

## Maintenance
- View predictions
- Schedule maintenance
- Track history
